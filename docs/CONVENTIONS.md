# Conventions

The rules for building any Korodexios project (small modules, spec and test first,
security, CI/CD, working with AI agents) ship with the package and are copied into every
project by `kdx init`.

- Print them: `kdx conventions` (English) or `kdx conventions --lang sk` (Slovak).
- Save them: `kdx conventions --write docs/CONVENTIONS.md`.
- Source: `src/korodexios_core/resources/conventions.md` and `conventions.sk.md`.
